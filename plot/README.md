## WAV Border Visualization

The `plot_wav_borders` function is provided to **visualize the onset and offset borders detected by the segmentation model**.

It reads the segmentation results from the `.tsv` file generated by the `inference` code and plots the detected borders on top of the corresponding WAV waveform. This provides a simple way to visually inspect the model predictions and check the locations of the detected speech segments.

In the generated plot:

- **Blue** represents the audio waveform.
- **Green dashed lines** represent the detected **onset borders**.
- **Red dashed lines** represent the detected **offset borders**.

### Input TSV Format

The function expects a `.tsv` file containing at least the following columns:

```text
wav_file
onset_sec
offset_sec
```

You can directly use the output `.tsv` file generated by the `inference` code.

If the TSV file also contains a `syllable_number` column, the detected segments are automatically sorted according to their syllable number before plotting.

### How to Use

First, import the function:

```python
from plot_wav_borders import plot_wav_borders
```

Then provide the paths to the inference TSV file and the WAV file you want to visualize:

```python
TSV_PATH = "/path/to/inference_results.tsv"
WAV_PATH = "/path/to/sub-01_run-01_trial-01.wav"

plot_wav_borders(
    tsv_path=TSV_PATH,
    wav_path=WAV_PATH
)
```

By default, the plot is displayed but not saved.

### Save the Plot

To save the generated figure:

```python
plot_wav_borders(
    tsv_path=TSV_PATH,
    wav_path=WAV_PATH,
    save_plot=True
)
```

If `output_path` is not specified, the figure is automatically saved beside the WAV file with `_borders.png` added to the filename.

For example:

```text
sub-01_run-01_trial-01.wav
sub-01_run-01_trial-01_borders.png
```

You can also specify a custom output location:

```python
plot_wav_borders(
    tsv_path=TSV_PATH,
    wav_path=WAV_PATH,
    save_plot=True,
    output_path="./plots/trial_01.png"
)
```

### Display and Save Without Showing the Plot

If you want to save the figure without displaying it:

```python
plot_wav_borders(
    tsv_path=TSV_PATH,
    wav_path=WAV_PATH,
    save_plot=True,
    output_path="./plots/trial_01.png",
    show_plot=False
)
```

### Function Parameters

- `tsv_path`: Path to the `.tsv` file containing the predicted onset and offset borders.
- `wav_path`: Path to the WAV file to visualize.
- `save_plot`: Set to `True` to save the generated figure. Default: `False`.
- `output_path`: Optional path for saving the figure. If not provided, the figure is saved beside the WAV file.
- `show_plot`: Set to `True` to display the figure. Default: `True`.

### Purpose

This visualization is mainly intended for **qualitative evaluation and debugging of the segmentation results**. It makes it easy to compare the detected onset and offset locations with the actual waveform and visually inspect the performance of the segmentation model.
